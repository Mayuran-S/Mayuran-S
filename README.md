## How I Think About Engineering

**Measure before guessing.**

**Fix the cause, not only the symptom.**

**Understand the hardware before blaming the firmware.**

**A prototype working once is not the same as a reliable product.**

**Firmware should still be understandable months after it was written.**

**Hardware, firmware, wireless and software should be designed as one system.**
